- T4 (2026-08-23): Batch 4 of the dengue-forecasting plan — got `chapkit_ewars_model`, the reference the plan's §2 names, running on the development dataset, so the project has a criterion for the first time. **Mean CRPS 21.891** over 16 provinces and 371 cells, MAE 28.504, 10–90 coverage 0.817 and 25–75 coverage 0.617 — close to nominal in the tails and materially over-dispersed in the middle, which is a specific opening for phase C. Pinned by image digest `sha256:abd8098f` (= source commit `a4c2fa42`); Docker was the whole obstacle and emulated amd64 R-INLA turned out to be fast, 149 s per eight-split backtest against 56 s for a native Python model — so **evaluation is not this project's binding cost**. **The reference is unseeded**: four identical runs gave CRPS 21.71–22.17, so any margin against it under about 0.4 CRPS is inside its own noise; Rule 6 cannot be satisfied for the model the success criterion names, and this was measured rather than assumed small. The unpaired split-level standard error is 5.65 CRPS (26 % of the mean), which bounds an unpaired comparison at roughly half the reference's whole score — phase C must compare paired per-cell instead. Model library: 39 repositories, the last published sweep covers 28 and reports **no metric of any kind**, so no leaderboard exists on Lao data; 23 of the 28 could be run on our file as it stands. Ranked shortlist produced, with spatio-temporal GNNs, the integrated superensemble and a mechanistic thermal backbone ruled out against the data rather than against the budget. Report: `26-08-23_b04_methodSurvey.md`. `/validate invariants` passes.
