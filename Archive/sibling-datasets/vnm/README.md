# sibling-datasets/vnm

The archived Vietnam monthly admin-1 series, pinned by commit and checksummed. Imported material:
read-only, never edited. The data files cannot carry an `(IS_SHADOW)` line without breaking
their own checksums, so the statement lives here and in `../provenance.md` instead.

**This project does not use these files.** Plan §4 lists the sibling datasets as "available as
an optional external check, not required", and no node under `analysis/` reads them. They are
kept because raw data is a re-usable resource and not the prior project's output. See
`../README.md` for the correction recorded in batch 19, and `../provenance.md` for the
checksums and how the data was obtained.
