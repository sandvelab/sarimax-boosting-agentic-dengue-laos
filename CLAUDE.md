# CLAUDE.md

**The standing instructions for this repository are in `AGENTS.md`. Read it in full before
doing anything here — it is the single source of truth, and this file carries no
instructions of its own.**

`AGENTS.md` is where the instructions live because they govern any agentic system working
in this repository, not one vendor's. This file exists because Claude Code loads
`CLAUDE.md` automatically, and its whole job is to send you to `AGENTS.md`.

Read, in order: `readme-at-start.md` (what this project is), `AGENTS.md` (how to work
here), `MOTIVATION.md` (why the repository is shaped this way).

The instruction files are part of the method — see `AGENTS.md` §3, Rule 4. Two runs of this
repository under different instructions are two different methods, so these files are
version-controlled with the same care as the analysis code, and are published with it.
