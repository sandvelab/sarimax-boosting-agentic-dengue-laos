# Human-AI-collaboration

The work product, and the bridge that connects it to the analysis.

| Path | Holds |
|---|---|
| `claims/` | The claim collection — every statement the analysis supports, bound to the result grounding it |
| `manuscript/` | The article, written from the claims |

The direction is one-way: results → claims → manuscript. Nothing enters the manuscript that
is not in the claim collection, and no claim exists without a pointer to a stored result.
